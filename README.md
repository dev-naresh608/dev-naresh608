I'm a **Full Stack Software Engineer** who builds end-to-end web applications — from pixel-accurate, performant frontends to secure, scalable backend systems. My core stack is **React, Next.js, Node.js, Express.js, and MongoDB**, and I care deeply about clean architecture, API design, and shipping software that behaves predictably in production.

My day-to-day work spans:

- 🧩 **Full Stack Development** — designing systems end to end, from UI to database schema
- ⚛️ **React Ecosystem** — component-driven architecture, state management, and reusable design systems
- 🔗 **Backend Development & REST APIs** — building resource-oriented, well-documented, versioned APIs
- 🔐 **JWT Authentication & RBAC** — secure, role-aware access control across multi-tenant applications
- 🗄️ **MongoDB & Schema Design** — modeling data for scale, consistency, and query performance
- ⚡ **Performance Optimization** — caching, lazy-loading, and render-path optimization
- 🏗️ **Clean Architecture** — layered, testable, maintainable codebases
- 📚 **Continuous Learning** — currently deepening my systems design and infrastructure knowledge

I enjoy solving real-world engineering problems — the kind that show up in production, not just in tutorials — and I take pride in writing code that a teammate can pick up a year later and immediately understand.
